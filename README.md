# Kali Linux for Omarchy

Tema inspirado en la identidad visual de Kali Linux: negro carbón, azul eléctrico,
superficies azul noche y tipografía de terminal. Incluye colores para Hyprland,
terminales, GTK, Walker, notificaciones, btop, OSD y pantalla de bloqueo.

Aplicar con `omarchy theme set kali-linux`.

La carpeta `backgrounds/` incluye 215 fondos oficiales obtenidos de los
paquetes publicados por Kali Linux. La configuración propia del tema está
licenciada bajo GPL v2; consulta [ATTRIBUTIONS.md](ATTRIBUTIONS.md) para los
términos de los fondos oficiales.
